# CodeAlpha C Internship

This repository contains C programming projects developed as part of my **CodeAlpha C Programming Internship**. These projects demonstrate my understanding of basic C programming concepts, problem-solving, and practical implementation.

## Projects

### 1. Calculator

A simple **Calculator program written in C** that performs basic arithmetic operations based on the user's choice.

**Operations included:**

* Addition
* Subtraction
* Multiplication
* Division
* Modulus

The program uses conditional statements and `switch-case` to perform the selected operation.

### 2. Matrix Calculator

A **Matrix Calculator written in C** that performs various operations on matrices using two-dimensional arrays.

**Operations included:**

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Matrix Transpose

The program takes matrix dimensions and elements as input from the user and performs the selected matrix operation.

## How to Run

### Calculator

Compile the program using GCC:

```bash
gcc calculator.c -o calculator
```

Run the program:

```bash
./calculator
```

### Matrix Calculator

Compile the program using GCC:

```bash
gcc matrix_calculator.c -o matrix_calculator
```

Run the program:

```bash
./matrix_calculator
```

**For Windows:**

```bash
calculator.exe
```

or

```bash
matrix_calculator.exe
```
